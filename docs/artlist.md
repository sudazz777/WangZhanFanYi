# Artlist 翻译

用于桌面浏览器的 Tampermonkey（篡改猴），支持常用界面翻译及可选歌曲名双语显示。

## 下载与安装

### [网站翻译 · v1.1.1](https://github.com/sudazz777/WangZhanFanYi/raw/refs/heads/main/downloads/websites-translation-v1.1.1.zip)

压缩包包含一个 `websites-zh-CN.user.js`、安装说明与 `GPL-3.0.txt`，支持 Artlist、Musicbed、GitHub 和 MiniMax Audio。

先停用旧的三个独立翻译脚本，再导入合并版。旧版设置和缓存不会自动迁移，在线翻译默认关闭。[安装与迁移说明](./使用说明.md)。

## 脚本内检查更新

首次请下载合并版 ZIP 并导入一次，停用旧的独立脚本。之后点击网站右下角 **中 / EN → 检查脚本更新**，或在篡改猴扩展菜单选择 **检查脚本更新**。发现新版后，点击“在线更新（篡改猴确认）”，在打开的安装页确认更新，再刷新网页。更新安装由篡改猴处理。

本版也已配置篡改猴原生更新地址。仓库现已公开，可在篡改猴管理面板使用“检查更新”，并按扩展设置定期检查；安装确认和自动更新频率由篡改猴控制。无需 GitHub 登录或令牌。检查只读取版本文件，不发送页面文字、输入内容或浏览 Cookie。网络不通或版本信息无效时会显示失败原因，也可回到仓库下载目录。

## 安装

**旧版更新：** 如果已安装“Artlist 简体中文助手（含歌曲界面）”，请先在篡改猴中停用旧名称脚本，再导入“Artlist 翻译”，避免两个脚本同时运行。

1. 在 Chrome、Edge 或 Firefox 中安装并启用 Tampermonkey。
2. 下载上方 ZIP 安装包并解压。
3. 打开篡改猴 **管理面板 → 实用工具 → 从文件导入**，选择解压得到的 `websites-zh-CN.user.js` 文件，并确认安装。
4. 打开或刷新 <https://artlist.io/royalty-free-music>。

Chrome / Edge 如提示用户脚本未获授权，请按 Tampermonkey 提示启用“允许用户脚本”（旧版可能要求扩展程序开发者模式）。

## 使用

- 安装后自动翻译常用导航、曲风、情绪、视频主题、乐器、筛选、排序和播放器文字。新增列表和弹窗按变化区域处理，大页面分批翻译；在线歌曲文字随滚动进入可见区域后补译，站内页面切换也会自动识别。
- 右下角 **中 / EN · 网站翻译（Artlist）** 是折叠菜单，也可通过篡改猴的脚本菜单切换。
- **开启歌曲名在线翻译**：阅读提示后确认，开始补译可识别的歌曲名、音乐描述和音乐正文。默认显示 `中文（English）`；可在菜单切换为仅中文。
- 在线翻译默认关闭，未开启时歌曲名保留原文，常用界面仍然中文。音乐人姓名尽量保留原文，不翻译音频或演唱内容。
- **显示英文原文** 可恢复脚本改动；**重新扫描 / 重试未译内容** 用于网络恢复或新内容未翻译时重试。

## 在线翻译、缓存和限制

在线部分使用 Google 的公开翻译接口，不需要 API Key；需要你的浏览器能访问 `translate.googleapis.com`。该接口不是有服务保证的付费 API，可能限流、变更或无法连接，尤其某些中国大陆网络环境。连续失败三次后会暂停请求，检查网络后点击重新扫描。本地词库不受影响。

开启在线翻译后，符合条件的页面文字会发送给 Google，翻译结果存入篡改猴本地存储，最多保留 2,500 条。请求不携带登录 Cookie；脚本不读取输入框的值，不发送搜索词、密码或可编辑区域的文字，并跳过可识别的表单、账户及账单区域。不要在显示私密内容的自定义音乐页面上开启在线翻译。可以用菜单清空翻译缓存；如果在线翻译仍开启，当前页面会重新请求翻译。

本脚本只修改页面显示文本和占位符等展示属性，不更改歌曲链接、搜索条件、播放和下载请求。翻译搜索框提示不代表中文搜索词会自动转换为英文。授权、价格和条款应以 Artlist 原文为准，歌曲名属于机器翻译参考。

已参考公开音乐首页文字，并在本地模拟页面验证动态内容、播放器更新、原文恢复、歌曲双语、缓存、输入内容保护、异步响应及失败重试。**当前环境无法连接真实 Artlist 做浏览器实测，未验证登录后的所有布局。** 歌曲识别同时使用链接路径、语义属性和常见类名；网站结构变化可能需要更新选择器，不能保证整站每处文字都已覆盖。
