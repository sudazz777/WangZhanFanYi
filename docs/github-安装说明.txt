GitHub 翻译 v1.0.1

安装
1. 在桌面版 Chrome、Edge 或 Firefox 中安装 Tampermonkey（篡改猴）。
   官网：https://www.tampermonkey.net/
2. 下载并解压本 ZIP 安装包。
3. 打开篡改猴 → 管理面板 → 实用工具 → 从文件导入。
4. 选择 github-zh-CN.user.js，确认安装。
5. 打开或刷新 https://github.com/

本版更新
补充全局菜单与仓库设置说明，修复布局容器误跳过和分段搜索提示。
保留分支、仓库输入值、代码和用户正文；仍只增量处理界面变化。

使用
常用仓库、议题、拉取请求、Actions 和设置控件自动使用本地词库翻译。
右下角“中 / EN · GitHub 翻译”可恢复英文或重新扫描。
代码、日志、文件名、分支、用户名、仓库名和用户正文尽量保持原文。

正文手动补译
在 README 或讨论正文中选中需要翻译的文字（最多 1500 个字符）。
在助手面板或篡改猴脚本菜单选择“翻译选中文字（在线）”。
确认原文预览后，所选文字才会发送给 Google 翻译，需要能访问其服务。
译文只显示在助手面板，不改写正文、不写入缓存，可点击“清空翻译结果”。
代码区和输入区不支持选中补译。不会自动上传整页或仓库内容。

更新
