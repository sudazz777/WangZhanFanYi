# 网站翻译

## 下载与安装

[网站翻译 · v1.1.0](https://github.com/sudazz777/WangZhanFanYi/raw/refs/heads/main/downloads/websites-translation-v1.1.0.zip)

解压后，在 Tampermonkey（篡改猴）的 **管理面板 → 实用工具 → 从文件导入** 中选择 `websites-zh-CN.user.js` 并确认安装。只需安装这一个脚本。

如果之前装过 Artlist 翻译、Musicbed 翻译、GitHub 翻译或 Artlist 简体中文助手，请先停用它们，避免同一个网页被重复处理。合并版使用独立的油猴存储，旧独立版的设置、在线授权和缓存不会自动迁移。安装合并版后，可按需重新设置。

## 使用与设置

右下角菜单显示“网站翻译（当前网站）”，可以切换中文/英文、重新扫描或检查更新。各网站的设置分别保存，例如关闭 Artlist 翻译不会关闭 GitHub 翻译。

- Artlist：可选开启歌曲名和描述在线翻译，默认保留原文。
- Musicbed：可选开启歌曲、音效名称和公开正文在线补译，默认关闭。
- MiniMax Audio：界面使用本地词库，不启用在线补译；歌词、提示词、原生选项值和生成参数保持原文。
- GitHub：界面本地翻译；选中 README 或讨论文字后，在篡改猴扩展菜单选择“翻译选中文字（在线）”，确认后补译；助手里不再显示此按钮。代码、输入框和用户标识尽量保留原文。

在线补译使用 Google 翻译，需要网络可访问；具体范围见各站说明。输入框的值不会被脚本翻译，脚本不会翻译音频。网站改版可能需要补充规则；减少闪现的效果受注入时机和页面大小影响。

## 检查更新

点击右下角助手或篡改猴扩展菜单的 **检查脚本更新**。各站均检查同一个“网站翻译”版本，发现新版后点击 **在线更新（篡改猴确认）**，在篡改猴安装页确认更新，再刷新网页即可，无需解压或导入。助手不再提供 ZIP 下载入口。支持篡改猴原生更新，周期和安装确认由扩展设置控制。

检查更新不发送页面文字和 Cookie。连接失败、超时或版本信息不正确时显示原因，可稍后重试或打开仓库下载目录。
