# v1.0.3 性能验证

卡顿相关的重复工作来自：弹窗增删后扫描父容器、样式类变化后扫描整棵子树、滚动后扫描整个 body，以及翻译写回触发的新一轮扫描。

本次改为只处理新增节点、变化的文字或展示属性；忽略自身的翻译写回和 class 变化。大列表按每批约 5ms、最多 240 个处理步骤让出主线程。在线翻译由 IntersectionObserver 跟踪可见内容，不再逐条读取布局或因滚动遍历全页。删除节点后的记录清理也分批执行。

本地 Chromium 中构造 1,800 行列表，间隔约 35ms 展开筛选 20 次，再触发 30 次滚动事件。一次对比结果如下；旧版批处理次数受事件时序影响，数字会略有变化。

| 场景 | v1.0.2 | v1.0.3 |
| --- | ---: | ---: |
| 初始加载遍历节点 | 12,604 | 12,604 |
| 连续展开筛选遍历节点 | 88,242 | 40 |
| 连续展开筛选的整页/主列表遍历 | 7 次 | 0 次 |
| 滚动遍历节点（离线词库模式） | 12,607 | 0 |
| 初始加载观察到的最大长任务 | 114ms | 无超过 50ms 的长任务 |

遍历量是脚本通过 TreeWalker 实际访问的后代节点数；单个展示属性更新单独处理，不计为子树遍历。测试同时断言点击后不扫描主列表、滚动不扫描整页，以免只依赖某一台机器的耗时。

复现需要 Node.js、Playwright 和 `/usr/bin/chromium`：

```sh
git show 7976245:artlist-zh-CN.user.js > /tmp/artlist-v1.0.2.user.js
node test/performance.test.cjs /tmp/artlist-v1.0.2.user.js --baseline
node test/performance.test.cjs
node test/browser.test.cjs
```

功能回归覆盖顶部导航、筛选弹窗、展示属性、歌曲节点复用、原文恢复、缓存、失败重试，以及歌曲滚入视口和仅通过 class 变化显示时的补译。测试使用本地页面和模拟翻译响应，未在登录后的真实 Artlist 页面测量；结果不代表网站本身和网络请求的耗时。


GitHub 的 1,800 行模拟列表同样只处理新增弹窗的 40 个后代节点，主列表重扫为 0 次，滚动遍历为 0。代码、差异、日志、文件名和用户正文另有保护断言；手动选中翻译只在确认后请求服务，不修改正文，也不缓存译文。

GitHub v1.0.1 增加截图对应的全局菜单、仓库设置布局、加粗/链接分段说明、快捷键提示及原文恢复回归。旧版在同一设置容器场景中无法完成翻译；新版通过，并保持 20 次点击只遍历 40 个新增节点、整页重扫 0 次的结果。这是模拟场景验证，未获取登录后的设置页 DOM。

### GitHub v1.1.0

设置页词库扩展为 117 个相关分组、7,238 条静态词条，仅编译当前设置路径需要的分组。可执行：

```sh
node test/github-settings.test.cjs
node test/github.test.cjs
node test/performance.test.cjs github-zh-CN.user.js --settings
```

独立用例覆盖 30 类路径、122 段菜单与说明，以及跨标签短句、链接/事件保留、显示标签与表单提交值隔离、节点复用、路径缓存更新和原文恢复。旧版 v1.0.1 在首个维基说明用例失败；新版通过。设置路径的大列表测试仍为 20 次点击处理 40 个新增节点，整页重扫、滚动扫描和锚点扫描均为 0；本次独立运行未观察到超过 50ms 的长任务。结果来自本地模拟场景，不代表登录后 GitHub 本身的网络和脚本耗时。

### GitHub v1.1.1：减少英文闪现

```sh
git show cae6b70:github-zh-CN.user.js > /tmp/github-v1.1.0.user.js
node test/github-render.test.cjs /tmp/github-v1.1.0.user.js --baseline
node test/github-render.test.cjs
node test/performance.test.cjs github-zh-CN.user.js --settings
```

测试在 HTML 解析前注入脚本，对首次动画帧取样，再在动画帧内模拟框架写入菜单，并在该帧的微任务检查点读取可见文字。导航同时触发 Turbo/PJAX，检查保留的头部和新内容。一次对照结果如下：

| 场景 | v1.1.0 检出可见英文 | v1.1.1 检出可见英文 |
| --- | ---: | ---: |
| 首次显示（4 帧样本） | 4 | 0 |
| 动态菜单（12 次写入） | 12 | 0 |
| 站内导航（4 次） | 4 | 0 |

额外暂停后台处理批次，验证局部待处理区域在 180 毫秒超时后恢复显示，并验证关闭中文、样式被替换后的恢复。大页面后台分批处理，每批目标为 4 毫秒、最多 320 步；不递归占满整个微任务队列。1800 行性能测试仍为 20 次点击只遍历 40 个新增节点、整页重扫 0 次，滚动和代码锚点扫描均为 0。

帧样本和微任务读数来自模拟页面，不是登录后网站的逐帧录像；数值随浏览器时序变化。提前注入、已收录词条和局部短等待可以减少闪现，但不能保证扩展延迟、未知文字或超大页面在所有环境中都完全没有原文露出。
