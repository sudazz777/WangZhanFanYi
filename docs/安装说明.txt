Artlist 翻译 v1.0.6

安装方法
1. 在桌面版 Chrome、Edge 或 Firefox 中安装 Tampermonkey（篡改猴）。
   官网：https://www.tampermonkey.net/
2. 解压本 ZIP 压缩包。
3. 打开篡改猴 → 管理面板 → 实用工具 → 从文件导入。
4. 选择解压后的 artlist-zh-CN.user.js，确认安装。
5. 打开或刷新 https://artlist.io/royalty-free-music

更新方法
首次从“Artlist 简体中文助手（含歌曲界面）”更新时，请先在篡改猴中停用旧名称脚本，再导入新版，避免两个脚本同时运行。
已安装“Artlist 翻译”时，导入新版 .user.js 文件并确认更新，然后刷新 Artlist 页面。
v1.0.4 将项目名称统一为“Artlist 翻译”，保留首页、AI 工具、素材库、工作室、工作流和所有筛选翻译。
优化点击与滚动速度，大页面分批翻译，在线歌曲文字进入可见区域后再补译；保留此前分类和高级筛选词库。

本版更新
新增“检查脚本更新”，并支持篡改猴原生更新检查。
提前处理本地界面，减少菜单先显示英文再变中文的闪现。
站内切换保留已有中文；大块新增内容分批处理，局部等待设有 180 毫秒超时。
在线翻译开启后，缓存名称直接显示译文；首次在线补译仍取决于网络。
更新后请刷新网站，并只启用一个同名翻译脚本。

使用方法
常用导航、音乐筛选及播放器文字自动使用本地词库翻译。
要翻译歌曲名和描述，点击右下角“中 / EN”，选择“开启歌曲名在线翻译”。
在线翻译会把符合条件的页面文字发送至 Google，需要能访问 Google 翻译服务。
在线翻译默认关闭；开启后歌曲名默认显示中英双语。
可在菜单选择“显示英文原文”或“重新扫描 / 重试未译内容”。

提示
请导入解压后的 .user.js 文件，不要直接导入 ZIP。
如浏览器提示需要用户脚本权限，请按篡改猴提示开启。
歌曲音频不会被翻译；授权、价格与条款请以 Artlist 原文为准。
已通过本地模拟浏览器测试，尚未在真实登录后的 Artlist 页面完整验证。

脚本内检查更新
首次从 ZIP 导入本版本后，在网站右下角助手或篡改猴扩展菜单点击“检查脚本更新”。
发现新版后下载 ZIP，解压导入 .user.js 并确认更新，再刷新网页。
也可用篡改猴管理面板的原生“检查更新”；周期和安装确认由扩展设置决定。
更新地址来自公开仓库，无需登录，不发送页面文字、输入内容或 Cookie。
网络失败时请稍后重试，或打开仓库下载目录手动下载。
