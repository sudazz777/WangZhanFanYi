GET STARTED

三步，使用中文界面。

适用于桌面版 Chrome、Edge 和 Firefox。

  1. 安装篡改猴

    从 Tampermonkey 官网安装浏览器扩展，按提示启用用户脚本权限。

  2. 解压并导入脚本

    下载 ZIP 后解压，在篡改猴“管理面板 → 实用工具 → 从文件导入”中选择 github-zh-CN.user.js 并确认安装。

  3. 刷新 GitHub

    打开或刷新 GitHub。右下角“中 / EN · 网站翻译（GitHub）”可以恢复英文、重新扫描或翻译选中文字。

GOOD TO KNOW

界面中文，内容由你决定。

如何检查脚本更新？

首次导入本版 ZIP 后，可在右下角助手或篡改猴菜单点击“检查脚本更新”，发现新版后下载 ZIP 并解压导入。也支持篡改猴原生更新检查，频率与安装确认由扩展设置控制。更新检查不发送页面内容。

README 和评论正文也能翻译吗？

选中需要翻译的说明文字，在右下角菜单点击“翻译选中文字（在线）”，或使用篡改猴脚本菜单。确认后会将所选文字发送给 Google 翻译，译文只显示在助手面板，不改写原页面。每次最多 1500 个字符。

代码和文件名会被修改吗？

脚本会跳过可识别的代码、差异、日志、编辑区、文件名、分支、用户名、仓库名和用户正文，不修改输入值、链接或操作参数。代码区和输入区不支持选中补译。

需要联网或 API Key 吗？

固定界面在本地翻译，不需要翻译服务或 API Key。手动正文补译需要能访问 Google 翻译，默认不会发送页面内容，译文也不写入本地缓存。

覆盖全部 GitHub 页面吗？

覆盖仓库、议题、拉取请求、自动化和设置等常用控件。已对真实公开页面 HTML 做离线验证，并通过 30 类设置路径、122 段文案和大列表性能测试；尚未完整验证登录后的所有界面，网站更新可能需要补充词库或选择器。查看完整说明。
